🎬 Movie Recommendation System (Content-Based)

A content-based movie recommendation system built using Natural Language Processing (NLP) and Machine Learning, designed to recommend movies based on semantic similarity between movie metadata.

This project demonstrates a complete end-to-end ML pipeline — from raw data preprocessing to vectorization and similarity-based recommendations.

📌 Project Overview

Traditional recommendation systems often rely on user ratings or collaborative filtering. This project instead focuses on a content-based approach, where recommendations are generated by analyzing and comparing movie attributes such as:

Plot overview

Genres

Keywords

Cast

Crew

By converting these attributes into numerical vectors and computing similarity scores, the system recommends movies that are contextually similar to a given input movie.

🚀 Key Features

Content-based recommendation (no user data required)

NLP-driven text preprocessing

Efficient similarity computation using cosine similarity

Scalable vector representation with controlled vocabulary size

Clean and modular preprocessing pipeline

🧠 System Architecture (High-Level)

Data Collection

Movie metadata dataset containing overview, genres, keywords, cast, and crew

Feature Engineering

Merge multiple textual attributes into a single unified feature (tags)

Text Preprocessing

Token joining

Lowercasing

Stop-word removal

Stemming using Porter Stemmer

Vectorization

Bag-of-Words model using CountVectorizer

Similarity Computation

Cosine similarity between movie vectors

Recommendation Output

Top-N similar movies returned for a given movie title

⚙️ Data Preprocessing & Feature Engineering

Combined multiple metadata columns (overview, genres, keywords, cast, crew) into a single tags column.

Converted list-based text fields into clean, space-separated strings.

Applied:

Lowercasing for normalization

Stop-word removal to reduce noise

Porter Stemming to reduce word sparsity (e.g., dance → danc)

This ensured a compact and semantically meaningful vocabulary.

📊 Vectorization Strategy

Used Bag-of-Words (BoW) model via CountVectorizer

Parameters:

max_features = 5000 to control dimensionality

stop_words = 'english' for noise reduction

Each movie is represented as a high-dimensional vector, enabling efficient similarity computation.

📐 Similarity Measurement

Applied cosine similarity to measure the angular distance between movie vectors.

Higher cosine similarity → higher contextual similarity between movies.

This approach is:

Computationally efficient

Scale-friendly

Widely used in real-world recommendation systems

🧪 Example Recommendation Flow

User selects a movie (e.g., Avatar)

System retrieves its vector representation

Cosine similarity is computed with all other movies

Top-N most similar movies are returned as recommendations
